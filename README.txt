QUANTUM VIEW

Keep index.html, index.css, script.js, and app.py in the same folder.

Install and run:
pip install flask
python app.py

Open http://127.0.0.1:5000 in your browser (do not use Live Server).

Optional Claude AI:
Install anthropic and python-dotenv, then set ANTHROPIC_API_KEY.
Without the key, the AI overview button displays a built-in portfolio summary.
